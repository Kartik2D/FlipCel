# FlipCel

A vector playground for drawing and animation.

Shapes merge and cut into each other as you paint. Edit anchors, scrub a timeline, and use timing-chart tools to move and morph art across frames — all in the browser.

**Live:** [kartik2d.github.io/FlipCel](https://kartik2d.github.io/FlipCel/)

## Features

- **Merge drawing** — brush & lasso with add / subtract / inside modes
- **Vector editing** — select, direct select (anchors / handles), magnet, eyedropper
- **Timeline** — keyframes, holds, onion skin, multi-frame edit, jog wheel
- **Symbols** — Flash-style reusable objects with their own timeline. Convert a selection (F8) or a frame range, place instances from the Library, edit in place, and set Loop / Play Once / Single Frame per instance
- **Magic Move** — draw a timing chart and bake selected art along a path into keyframes
- **Magic Morph** — chart-driven morph between poses; Auto Morph over a range
- **UI** — dockable panels, themes, touch-friendly viewport
- **Export** — SVG, JSON, or JS document export
